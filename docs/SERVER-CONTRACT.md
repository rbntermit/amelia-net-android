# Контракт приложения с сервером подписки

Для разработки. Сервер подписки — отдельный проект; всё, что ниже, меняется только по согласованию с ним
(см. CLAUDE.md: `/app/hints`, `/app/probe`, `/app/report`, `/app/crash`, `/app/support`, `version.json`).
Как приложение пользуется этими ответами — в [LOGIC.md](LOGIC.md).

Во всех примерах ключи, id и адреса выдуманные: IP — из документационных диапазонов (`192.0.2.x`,
`198.51.100.x`, `203.0.113.x`), AS — из частного диапазона, операторы — без настоящих названий.

## Адреса

- Российские зеркала — `AmeliaConfig.ENTRIES` (единственное место, где записаны их имена и адреса), затем основной
  домен `sub.ameliajustamelia.com` и запасной `sub.ameliajustamelia.net`. Порядок для каждого вида запросов задан в
  коде (`SUB_BASE_URLS`, `AmeliaNetwork.POST_BASE_URLS`, `SITE_BASE_URLS`, `RESUBSCRIBE_BASE_URLS`) и описан в
  LOGIC.md, «Входы и зеркала».
- Подписка: `GET {база}/sub/<ключ>`. Ключ = id подписки. Ссылка `amelia://key/<ключ>` открывает приложение и сразу
  входит.
- Гео-базы (только РФ): `{база}/geo/geoip.dat` и `{база}/geo/geosite.dat` — при первом запуске и раз в сутки.
- Обновления: `{база}/app/version.json`, APK рядом в `/app/`. CI кладёт `version.json` в релиз рядом с APK
  (другой адрес APK — переменная репозитория `APK_BASE_URL`).

## Общее для POST-запросов

Тело — JSON, `Content-Type: application/json`, не больше 64 КБ. Адреса — `AmeliaNetwork.POST_BASE_URLS` по порядку:
сначала через обычную сеть телефона мимо VPN (`"path": "direct"`), если не вышло — через туннель (`"path": "tunnel"`).

User-Agent всех запросов: `AmeliaNet/<versionName> v2rayNG/<upstream> Xray/<версия ядра> Pick/<manual|auto>`.
Начало `AmeliaNet/<версия>` и `Xray/<версия>` не меняются: по ним бот считает установки и версию ядра. С 1.8.2
`Pick/manual` — локацию выбрали вручную, иначе `Pick/auto`; вся строка не длиннее 200 знаков (сервер хранит первые 200).

## POST /app/report

Кнопка «Не работает — сообщить». Ключ уходит только здесь и в `/app/support`, оба — по нажатию человека.

```json
{"key": "<sub_id подписки>", "ts": 1700000000, "app": "1.1.0", "code": 7, "xray": "26.10.10",
 "hy2": "xray-26.10.10", "android": "14", "device": "Google Pixel 8", "tv": false,
 "net": "mobile", "op": "Оператор A", "path": "direct", "active": "<имя сервера, на котором был>",
 "bypass_ru": true, "comment": "<до 500 символов>",
 "servers": [{"name": "Нидерланды 1", "host": "192.0.2.10", "port": 2079, "ok": false, "ms": null,
              "stage": "connect", "err": "<до 200 символов>"}]}
```

- С 1.2.0: `"check_ms": 9400` — сколько заняла проверка всех серверов, мс; `"events"` — до 20 последних
  автоматических переключений `[{"ts": <unix>, "from": "Нидерланды 1 🇳🇱", "to": "Финляндия 2 🇫🇮",
  "why": "нет ответа 2 раза · 9 с"}]` (в `why` после « · » — за сколько секунд нашёлся рабочий сервер).
- С 1.5.4: `"vpn": true` — был ли включён VPN при отправке; `"sub_active": true` — действует ли подписка
  (`expire` 0 или впереди); `"journal"` — до 20 последних строк «Журнала» (`"22.10.2026 14:05 Нет интернета"`, до 160
  символов, старые первыми). Ключ — только в `"key"` (по нему бот находит подписку и отвечает), в тексте для бота его нет.
- С 1.7.1 — необязательное `"play_protect"`, только если Google Play Защита не дала установить обновление и эта версия
  ещё не установлена: `{"code": 28, "at": <unix>, "count": 2, "status": 3, "msg": "INSTALL_FAILED_VERIFICATION_FAILURE: Install not allowed"}`
  (`code` — какую версию не дали поставить, `at` — когда последний раз, `count` — сколько раз). Без блокировки поля нет.

Ответ: `{"ok": true, "id": "R1234"}`. `net`: `mobile` | `wifi` | `other`. `stage`: `connect` — к серверу не
соединиться; `data` — соединение есть, но запрос через сервер не проходит; `ok`. `hy2`: hysteria2 встроен в
Xray-core, поэтому здесь `xray-<версия Xray-core>`.

## POST /app/support (с 1.8.0)

Экран «Поддержка», только по кнопке «Отправить». Адреса и пути — как у `/app/report`; 400 и 429 — окончательный ответ,
следующий адрес не спрашивается.

```json
{"key": "<sub_id подписки>", "text": "<до 1500 символов>", "about": "<до 4000 символов>", "app": "1.8.0"}
```

`about` — текст «Скопировать для поддержки» из «О программе», локация, включён ли VPN и до 20 строк «Журнала»; без ключа
и личных данных. Ответ: `{"ok": true, "id": "W-XXXXXX", "h": "<24 hex>"}`. Ошибки: 400 `{"err": "empty"}` или
`{"err": "bad key"}`, 429 — больше 6 сообщений за 10 минут, 500.

## POST /app/support/thread (с 1.8.0)

Переписка, без ключа:

```json
{"h": "<первые 24 hex sha256(\"amelia-support:\" + ключ)>"}
```

Ответ: `{"ok": true, "items": [{"id": "W-1A2B3C", "ts": 1700000000, "d": "in", "x": "текст"}]}` — до 30 сообщений,
старые первыми; `d`: `in` — от человека (и его отчёты `/app/report`: «📨 Отчёт R-… из приложения: …»), `out` — ответ
поддержки. 429 — чаще 30 раз за 10 минут. Приложение спрашивает раз в 30 с, пока открыт экран, и раз в 15 минут в фоне,
пока ждёт ответа (последнее сообщение — его, моложе 7 дней).

Контрольное значение (выдуманный ключ): `0123456789abcdef` → `44ee8fa78a1c317551f4ab5a`.

## POST /app/probe

Фоновые проверки для карты блокировок (переключатель «Помогать находить блокировки», включён по умолчанию):

```json
{"iid": "<случайный id установки>", "ts": 1700000000, "app": "1.1.0", "net": "mobile",
 "op": "Оператор A", "path": "direct",
 "servers": [{"host": "192.0.2.10", "port": 2079, "ok": true, "ms": 230, "stage": "ok"}]}
```

Ответ: `{"ok": true}`, ошибки не показываются. Без имён серверов, ключа, UUID, номера телефона и сайтов. Отправка: не
чаще раза в 6 часов на одну сеть; через 10 минут, если сервер, который работал, перестал (не чаще раза в час); один раз
при смене сети (Wi-Fi ↔ мобильная, другой оператор).

## GET /app/hints (с 1.2.0)

Что сейчас не работает у провайдера того, кто спрашивает. Те же адреса и порядок, только мимо туннеля, без ключа (сервер
считает по AS). Приложение спрашивает при запуске, при смене сети и раз в 30 минут, ответ хранит 30 минут, ошибки
игнорирует:

```json
{"asn": 64500, "as": "Example Operator", "cc": "RU",
 "bad": [{"host": "192.0.2.10", "port": 2079, "bad": 3, "of": 4, "stage": "data"}], "ts": 1700000000}
```

Серверы из `bad` уходят в конец очереди автовыбора, если собственная проверка не показала, что они работают.

## POST /app/crash (с 1.3.0)

Отчёты о сбоях, переключатель «Отправлять отчёты о сбоях» (включён по умолчанию). Падения во всех процессах и
нефатальные ошибки (`where`: `core_start`, `vpn_service`, `update`, `update_blocked`, с 1.5.3 `update_stuck`, с 1.5.4
`boot_start`, с 1.5.5 `update_cancel` — не чаще раза в сутки) сохраняются в файл и уходят при следующем запуске, мимо
туннеля, не больше 5 в час:

```json
{"iid": "<тот же id установки>", "ts": 1700000000, "app": "1.3.0", "code": 11, "xray": "26.10.10",
 "android": "17", "device": "Google Pixel 8", "thread": "main", "where": "", "fatal": true,
 "stack": "process: com.ameliajustamelia.vpn:daemon\n…"}
```

Из стека перед отправкой удаляются ключ подписки (и любые 16 hex), UUID, ссылки `vless://`, `hysteria2://`,
`trojan://` и т. п., адреса `…/sub/…`, пароли, IPv4 и IPv6, кроме адресов наших серверов
(`AmeliaConfig.OUR_SERVER_IPS`). Первая строка стека — процесс.

## version.json

```json
{"versionCode": 2, "versionName": "1.0.1", "url": "https://sub.ameliajustamelia.com:9443/app/AmeliaNet_1.0.1_universal.apk",
 "sha256": "…", "size": 74947722, "notes": "Текст из changelog/ru/2.txt", "minVersionCode": 1,
 "abis": {"arm64-v8a": {"file": "AmeliaNet_1.0.1_arm64-v8a.apk", "sha256": "…", "size": 30911895}}}
```

Поля `versionCode, versionName, url, sha256, size, notes` используют бот и скрипт выкладки — их нельзя переименовывать
или удалять, новые поля можно только добавлять. С 1.3.0 `abis` — APK под arm64-v8a (около 31 МБ вместо 75), только
имя файла: сервер кладёт его рядом с universal в `/app/`, приложение берёт адрес оттуда же, откуда пришёл
version.json, и проверяет `sha256` из `abis`. `url` и universal остаются для старых версий и бота. `minVersionCode` —
см. RELEASING.md.
