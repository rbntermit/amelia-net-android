# Amelia.Net для Android — план

Основа: v2rayNG 2.3.11 (github.com/2dust/v2rayNG, GPL-3.0), ядро — AndroidLibXrayLite v26.10.10
(Xray-core v26.10.10). Пакет исходников `com.v2ray.ang` оставлен как есть, чтобы проще подтягивать
обновления апстрима; наш код лежит в `com.v2ray.ang.amelia`. applicationId — `com.ameliajustamelia.vpn`.

## Этапы

1. **Первая сборка (готово):** пункты 1–4, плюс базовые правила из п.5 без гео-баз и показ
   заголовков из п.6. Проверено: компиляция, 14 юнит-тестов (ключ, заголовки, правила, разбор наших
   ссылок hy2 и vless+reality+xhttp+mlkem), состав APK. Не проверено: подключение на телефоне.
2. **Гео-базы (готово):** `AmeliaGeoUpdater` качает `/geo/geoip.dat` и `/geo/geosite.dat` при
   первом запуске и раз в сутки (в приложении и фоновой задачей WorkManager), с запасным доменом.
   Файл заменяется атомарно и только если похож на protobuf (первый байт 0x0A), иначе остаётся
   старый. Правила `geosite:category-ru`/`geoip:ru` включаются, когда оба файла на месте; если в
   этот момент VPN работает, он перезапускается. Реальные файлы с сервера проверены: внутри есть
   `RU` и `CATEGORY-RU`.
3. **Автообновление (готово в приложении, ждёт сервер):** `AmeliaUpdater` раз в 6 часов и по пункту
   меню читает `/app/version.json`, показывает карточку «Доступна новая версия», качает APK,
   сверяет sha256 и открывает системный установщик. URL APK принимается только https и только с
   доменов ameliajustamelia.com/.net и GitHub. CI генерирует `version.json` к каждой сборке —
   его и universal-APK нужно выложить на сервер в `/app/`.
4. **Чистка (готово):** из исходников и манифеста удалены экраны v2rayNG — главный экран, редакторы
   серверов, подписки, маршрутизация, настройки, гео-файлы, бэкап, логи, проверка обновлений
   GitHub, сканер QR, импорт по ссылкам, Tasker; убрана CameraX. Остались ядро, сервисы, плитка и
   виджет. При слиянии с новыми версиями v2rayNG конфликты «изменён/удалён» решаются удалением
   (`git rm`).

## Что нужно со стороны сервера

- **Запасной домен — сейчас не работает.** В приложении зашито
  `https://sub.ameliajustamelia.net:9443/sub/<ключ>`. Проверка 14.10.2026: имя резолвится и порт
  отвечает, но TLS падает с `SEC_E_WRONG_PRINCIPAL` — в сертификате нет `sub.ameliajustamelia.net`
  (в `sub_server.py` подключён только `live/sub.ameliajustamelia.com`). Нужно выпустить сертификат,
  покрывающий оба имени (`certbot -d sub.ameliajustamelia.com -d sub.ameliajustamelia.net`), и
  перезапустить subserver. Если на .net другой поддомен или порт — поправить
  `AmeliaConfig.SUB_BASE_URLS`. Основной домен проверен: на неизвестный ключ отвечает 404, как и
  ожидает приложение.
- **Ссылка из бота.** Telegram не пускает `amelia://` в кнопки (та же история, что с `happ://`), поэтому
  нужен https-редирект по образцу `/open/<sub_id>`. Набросок для `sub_server.py`:

  ```python
  @app.route("/amelia/<sub_id>")
  def open_amelia(sub_id):
      if not re.fullmatch(r"[A-Za-z0-9_-]{4,128}", sub_id):
          abort(404)
      return redirect(f"amelia://key/{sub_id}", code=302)
  ```

  Кнопка в боте: `https://sub.ameliajustamelia.com:9443/amelia/<sub_id>`. Если приложение не
  установлено, браузер покажет ошибку — тогда лучше отдавать HTML-страницу со ссылкой
  `amelia://…` и ссылкой на скачивание APK.
- **Версия приложения (п.7).** Предлагаемый формат `GET /app/version.json`:
  `{"versionCode": 2, "versionName": "1.0.1", "url": ".../app/AmeliaNet-1.0.1-universal.apk", "sha256": "...", "notes": "..."}`.
- **Гео-базы (п.5).** Отдельный `GET /geo/meta.json` с полем `built`, чтобы не тянуть файлы зря.

## hysteria2: поддержка

Ничего дописывать не нужно: v2rayNG 2.3.x отдаёт hysteria2 в само ядро Xray (протокол `hysteria`,
`version: 2`), отдельного бинарника hysteria больше нет. Ваши ссылки
`hy2://<пароль>@<ip>:<порт>/?sni=...` разбираются штатно (`AppConfig.HY2` → `Hysteria2Fmt`).
Ваши текущие ссылки (`sni=msk1…`, `obfs=salamander&obfs-password=…`) подходят как есть: пароль
идёт в `hysteriaSettings.auth`, obfs — в `finalmask.udp` с типом `salamander`, SNI — в TLS.

Что проверить:
- на устройстве: подключение к «Антиблок Финляндия» и «Антиблок Казахстан» (UDP 8444/8454);
- `HY2_OBFS` и `hy2_pass()` в `sub_server.py` вставляются в ссылку без URL-кодирования. `+` приложение
  сохраняет, но `% & # = @ :` в этих строках сломают разбор. Если такие символы возможны, на сервере
  их нужно оборачивать в `urllib.parse.quote(..., safe="")`;
- `up`/`down` из ссылки приложение не читает — работает обычный BBR, как у вас и задумано;
- самоподписанный сертификат потребует `pinSHA256=`; сейчас сертификат настоящий, не нужно.
